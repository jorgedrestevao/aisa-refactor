# Nota do responsável de compras — pedidos urgentes (sintético)

Data: 2026-10-01

[U1] A partir de agora, um pedido urgente continua a ir directamente a compras, mas a chefia passa a ter até ao fim do dia útil seguinte para o validar, e não até ao fim do mesmo dia.

[U2] Se a chefia não validar dentro desse prazo, compras suspende a encomenda até haver validação.
